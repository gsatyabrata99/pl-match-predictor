# Tuning experiment — 2026-11-05

## Protocol

| | |
|---|---|
| Objective | Mean multiclass log loss (primary); Brier, 1X2 accuracy, draw calibration, calibration bins (secondary) |
| Development seasons | 2022-23, 2023-24 — all tuning and selection |
| Test seasons | 2024-25, 2025-26 — **sealed**, not evaluated in this experiment |
| Prediction rule | Walk-forward: each gameweek predicted from matches that kicked off before that gameweek's first kickoff, plus a prior from the previous season only |
| Data | vaastav/Fantasy-Premier-League at commit `d7b05b51d137bfefef4b692386d18c610975b9b9`; file hashes in the JSON outputs |
| Regenerate | `python -m predictor.evaluate tune` then `python -m predictor.evaluate compare` |

Grid: xG weight {0.5, 0.6, 0.7, 0.85, 1.0} × prior games {4, 8, 12, 20} × prior shrink {0.6, 0.75, 0.9} × league-average prior matches {0, 40, 100, 200, 380} × ρ {−0.2 … 0.05}: 2,100 configurations. Prior games was then extended to {1 … 6} because the optimum sat on the grid edge.

## Data fix found during this work

2022-23 has no xG for GW1–15 (FPL added expected stats mid-season); the archive stores those weeks as 0.0. These are now treated as missing rather than as matches in which neither side created a chance. Affects historical evaluation only; current-season data comes from the live FPL API.

**League-average prior.** Anchoring home/away averages to last season was expected to help and does not. Scoring shifted between seasons (2.85 goals per match in 2022-23, 3.28 in 2023-24 after the added-time changes); the current season's own averages track that shift, while a prior lags it. Before any current-season match the averages already fall back to last season's, so the early-season case is covered with `mu_prior_games = 0`.

## Chronological check

Parameters chosen on 2022-23 alone (xG 1.0, prior 4, shrink 0.6, ρ 0) scored **0.9373** on 2023-24, worse than the untuned baseline's **0.9350**. Selecting several parameters from one season mostly fits noise; only the prior-strength and ρ signals are consistent across both seasons.

## Results on development seasons (n = 760)

| Model | Log loss | Brier | Accuracy | Mean draw prob (actual 0.222) |
|---|---|---|---|---|
| Base rates (last season's H/D/A) | 1.0555 | 0.6377 | 47.2% | 0.230 |
| v0.1 baseline | 0.9629 | 0.5700 | 54.7% | 0.237 |
| **Recommended: prior 4, ρ 0** | **0.9606** | **0.5688** | **55.4%** | **0.220** |
| Full grid best (also xG 0.85) | 0.9604 | 0.5687 | 55.3% | 0.220 |

Log loss change, recommended − baseline: **−0.0023**, 95% paired bootstrap interval **[−0.0072, +0.0025]**. Both development seasons improve (2022-23: 0.9909 → 0.9864; 2023-24: 0.9350 → 0.9348), but the interval includes zero and the figure is in-sample for tuning, so it is an optimistic estimate.

Aggregate goals: predicted 1.66 home / 1.35 away against 1.72 / 1.35 actual (home slightly under-predicted by both versions). Calibration is close across bins for both versions; the 0.5–0.6 bin is under-confident (0.55 predicted, 0.58–0.61 observed).

## Recommendation

Adopt the minimal change (prior games 8 → 4, ρ −0.08 → 0), keeping the other v0.1 values. It captures nearly all of the measured gain with two parameters, both with consistent signs across seasons. The xG weight change is not adopted because its effect is smaller than its noise.

Expected effect: a small improvement, mainly better draw calibration and faster adaptation to this season. The held-out test is the evidence that decides whether it is real.

## Decision (2026-11-05)

| Item | Decision |
|---|---|
| Prior games 8 → 4 | Approved **provisionally** |
| ρ −0.08 → 0 | Approved **provisionally** |
| xG weight stays 0.7 | Approved |
| League-average prior stays off | Approved |
| Missing-xG correction, evaluation harness | Approved |

The updated model is **nominated as the candidate before the held-out test is opened**. The test compares the frozen v0.1 and the frozen candidate on identical 2024-25 and 2025-26 fixtures, once, with no further tuning. Its result is reported as the estimate for the nominated candidate; it is not used to pick between the two models after the fact. Any change made after seeing the test results must be labelled exploratory.

Caveats recorded with the decision:

- The gain is about 0.24% of log loss, with an interval that includes zero.
- Parameters chosen on 2022-23 alone did worse on 2023-24, so results may depend on season-specific conditions. A 4-game prior is the best value found here, not a universal constant.

## Future research (no new parameter yet)

Scoring environment: goals rose from 2.85 to 3.28 per match between 2022-23 and 2023-24. The current-season league averages already re-estimate scoring as matches accumulate; check how quickly they adapt, and whether early-season predictions after such a shift are miscalibrated, before introducing anything to model it.

## Disclosure

Before this protocol existed, an earlier, different v0.1 backtest of 2025-26 (from GW4, no previous-season prior) was viewed: 48.6% accuracy, Brier 0.620. Those numbers did not inform any choice in this experiment, but 2025-26 was not entirely unseen before the split.
